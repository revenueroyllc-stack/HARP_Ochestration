# M.A.X.I.N.E. Tool Policy

## Purpose

This policy defines what M.A.X.I.N.E. may request, what requires approval, and what is forbidden.

## GREEN Actions

- answer general questions
- summarize local notes
- create local note
- search public web
- search YouTube
- read non-sensitive calendar availability
- draft email without sending
- create personal reminder
- open local cockpit URLs
- search Onyx knowledge base

## YELLOW Actions

- create calendar event with another person
- reschedule meeting
- send email
- forward email
- save memory candidate to Ra
- summarize business-sensitive material
- hand task to OpenHands
- search vendor, product, or pricing information
- open external links found by web search

## RED Actions

- delete email
- send legal, immigration, financial, or compliance-sensitive email
- access production secrets
- push code
- deploy code
- change billing
- alter database
- submit forms
- purchase anything
- log into accounts
- scrape private or paywalled content
- bypass authentication
- download unknown files
- execute shell commands outside approved sandbox

## Microsoft Scope

- Microsoft Outlook email: executive@revenueroyllc.com
- Microsoft Calendar: executive@revenueroyllc.com

## Web Research Rule

Maxine may search the public web, read public pages, summarize public information, compare sources, and save useful links to notes.
Maxine may not enter passwords, fill forms, make purchases, bypass logins, scrape private content, or download unknown files.

## NotebookLM Rule

NotebookLM is a research workspace, not the authority layer.
Onyx remains the primary local RAG lane.
Ra remains the governed memory and truth layer.

## Forbidden Direct Access

M.A.X.I.N.E. must not directly own raw production keys, database credentials, billing credentials, unrestricted shell, Docker socket, deployment credentials, or unrestricted browser automation.
